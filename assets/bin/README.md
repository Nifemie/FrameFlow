# FFmpeg Binaries

Place `ffmpeg.exe` and `ffprobe.exe` in this directory for local development and build packaging.
Due to GitHub file size limits (>100MB), the binary executables are excluded from version control.

Download FFmpeg from https://ffmpeg.org or Gyan.dev (essentials build) and place:
- `assets/bin/ffmpeg.exe`
- `assets/bin/ffprobe.exe`
